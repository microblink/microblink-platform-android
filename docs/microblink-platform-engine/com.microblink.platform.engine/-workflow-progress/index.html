WorkflowProgress

data class WorkflowProgress(val stepCount: Int?, val interactiveStepCount: Int?, val hasConditionalInteractiveStep: Boolean, val isKioskModeEnabled: Boolean, val steps: List<Step>, val currentStepId: Int?, val completedStepIds: List<Int>)

Snapshot of the workflow's progress as known to Engine at a point in the session. Carries the data a home / progress screen needs. steps lists interactive steps only; the counts are null until the backend has sent a snapshot.
