EngineError

sealed class EngineError

A failure surfaced by Engine. The caller should not infer retry behavior from the error type alone; it should use StepResult.Failed.recoverable and StepResult.Failed.retryAction.

Engine maps every backend error to one of these; raw backend codes are never exposed.

data class MissingScannerSdk(val stepType: EngineStepType) : EngineError

The workflow has a scanner step whose SDK this app doesn't include, so the step can't run — an integration error, terminal. Engine compiles against the scanner SDKs but doesn't bring them: the app adds BlinkID Verify for EngineStepType.DocumentScan and EngineStepType.VerifyDocument, BlinkCard for EngineStepType.CardScan and Biometrics for EngineStepType.FaceCapture, at the versions the platform BOM gives.
