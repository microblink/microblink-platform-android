ScannerTypography

data class ScannerTypography(val onboardingTitle: TextStyle? = null, val onboardingText: TextStyle? = null, val onboardingButton: TextStyle? = null, val helpDialogTitle: TextStyle? = null, val helpDialogText: TextStyle? = null, val helpDialogButton: TextStyle? = null, val errorDialogTitle: TextStyle? = null, val errorDialogText: TextStyle? = null, val errorDialogButton: TextStyle? = null, val scanningInstructions: TextStyle? = null, val helpTooltip: TextStyle? = null, val loadingScreen: TextStyle? = null, val faceCaptureInstructions: TextStyle? = null)

The fonts of the scanner and face screens. A style replaces that text's whole default style, so set its size too; a null style keeps the SDK's own. A style's color may be ignored, because the scanner screens take their text colors from ScannerColors.
